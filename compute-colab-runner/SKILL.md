# 算力与 Colab 执行

先确认本轮计算目标、入口、数据版本、评价口径、时间/费用上限与允许上传的平台。读取当前项目规则和最近一次实测；使用已有环境与入口，不为新轮次自动新建笔记本。用户指定平台是约束，不静默换平台；本Skill不赋予账号、上传、安装或付费权限。

## 资源决策

1. 优先本机。以选定解释器运行 `scripts/probe_resources.py --disk-path <项目目录>`，得到只读设备、磁盘、已安装库版本及电量/供电状态报告。该报告不加载模型、不训练、不访问网络，也不能证明显存或速度足够。
2. 在计算任务已授权后，用实际模型和小批量短测估计总耗时/峰值显存，计入本轮预算。留出评测、保存和中断余量；依赖缺失是环境问题，不能直接判定硬件不够。
3. 本机确实不足或不满足用户约束，再核实免费云是否实际可分配。免费入口不等于可用额度；未公开限制记未知。失败不循环新开会话，不终止其他任务资源。
4. 仍不足时，给出平台/配置、实测依据、最小购买量、总费用上限及存储/空闲费用，经明确批准再开通。不因模型效果差自动买更强GPU。

资源门槛应有当前负载、实测峰值和保护余量依据，不把旧快照或任意阈值永久当成无路可走。用户要求降低门槛时评估小批量、分段或低内存路径，保留必要运行保护；不能只改数字追求启动。条件实际改变后可在剩余授权内重做有界预检，不因唤醒次数增加重试。

## 执行分支

本机长时计算前检查电量百分比、是否接通电源及充电状态；无法读取记未知，不当作已接电。笔记本优先接电运行。未接电且系统报告低电量、剩余电量不高于20%（默认保护阈值，可按任务调整），或用户提示即将没电时，不启动新的重计算；运行中先保存/确认已有完整检查点，再停止本任务计算，提醒接电。长任务随进度定期复查供电；不得为此修改系统电源设置或终止其他任务。中断如实记录，未保存步骤不算完成；恢复前复核预算和重试约束，不自动开启新一轮训练。

- 仅评估：交付资源事实与缺口，不训练。
- 本机运行：复用项目脚本/隔离环境，记录实际命令和配置，不把本机短测数字推广到不同模型。
- Colab准备、执行或恢复：先读 [Colab流程](references/colab.md)。本Skill只提供方法与资源检查，不是Colab连接器，不能保证登录、云GPU或永久会话。
- 学习实验：先读 [实验证据与交付](references/experiment.md)。非学习型计算不强制采用训练/评测划分。
- 有绝对截止、长时/后台运行或多次恢复的任务：先读 [有界运行与收束](references/bounded-execution.md)，采用本环境已验证的进程归属与停止机制；普通只读资源查询不强制搭建监督服务。

运行前确定停止条件与重试预算；恢复先检查真实进程、日志和已有输出，活跃任务只观测，不重复启动。失败区分环境、资源、数据、数值、训练拟合、开发效果和未见测试；某一固定配方失败不等于所有路线失败。长任务采用当前产品支持的状态/等待机制，不承诺本轮结束后仍会自动监控。

结束明确区分资源检查、实际执行、质量达标；给结果图/可用产物、耗时费用、证据和限制。确需人工判断时直接交付具体对象，不先审批审核页面。
