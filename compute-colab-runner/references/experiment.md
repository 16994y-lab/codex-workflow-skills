# 实验证据与交付

运行前记录：唯一假设、基线、数据版本、训练/开发/保留评测分组、指标与匹配规则、配置/代码/初始权重身份、预算和停止条件。优先一次验证一个变化；复杂联合变化应说明无法归因，不能称单因素对照。

假设同时说明结果将改变哪项下一决策。复用现有实验记录，保留固定配方、实际结果、关闭原因及重开所需的新证据；不为每次唤醒另造一套文件。重试若为排除环境错误或测量随机波动，事前说明目的和预算。一个配方失败只关闭该配方，但重复的拟合改善/泛化恶化应触发路线复核，而不是无限加步或扫参数。

文件数不等于不同照片数，裁图不等于独立拍摄；同一父图、近重复、同次拍摄或同一对象关系需按任务防止跨集泄漏。未知标注不当背景。曾经用于开发选择的集合不能重新称独立盲测。

先验证数据与坐标/标签含义，再训练；用于表示方向的辅助点不自动等同于实际对象的关键点。新增分支有梯度、参数更新不证明学会了该能力。针对任务同时检查检出、定位、关联或方向本身，不用部分正确掩盖整条链路失败。

固定评测口径，模型保存后核对可加载性；记录实际预测和匹配来源。训练曲线、训练集效果、开发检查、独立评测分开报告。保留失败结果，不修改验收阈值制造成功。

评价失败与运行失败分开：未加载模型的资源拒绝、数值训练异常、已完成但质量未过，不能合并成同一种失败。正式定位容差等尚未确定时可以预声明临时研究标准，既不以此冻结全部研究，也不称产品达标。研究工具完成、历史样本无需人工修正和真实新材料上的质量/人工负担是不同证据。

图像反馈标明原图、人工真值、模型输出、命中/漏检/误报及集合身份；未知点单独处理。能自动验证的身份、范围、计数和一致性由助手完成，只将真实视觉/业务歧义交给用户。

交付至少包含：配置与来源清单、运行日志/退出状态、模型或产物位置、实际结果与指标、可视化、实际耗时费用、已做/未做检查、下一步。不要求把原图或模型大文件提交Git。
